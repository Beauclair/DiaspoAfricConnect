🌍 DiaspoAfricConnect — Icon Generator

Generate clean, professional text-based icons for the app.

After downloading:

  1. Move icon.png → assets/icon.png
  2. Move android-icon-foreground.png → assets/android-icon-foreground.png
  3. Move android-icon-background.png → assets/android-icon-background.png
  4. Move android-icon-monochrome.png → assets/android-icon-monochrome.png
  5. Move splash-icon.png → assets/splash-icon.png
  6. Move favicon.png → assets/favicon.png
  7. Run npx expo prebuild --clean to regenerate native icons
